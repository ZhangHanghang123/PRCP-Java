## 四、踩坑与修复

### 1.1 KPI 公式解析异常（MyBatis `${}` 触发 SQL 注入）

**问题**：公式中用 `${balance_x}` 占位符，被 MyBatis 当成 `${}` 替换报错。

**修复**：公式使用 `#{paramName}` 或自定义占位符（`@FUNC{balance_x}`），由应用层解析。

### 1.2 评分规则段 `min_value=null` 不生效

**问题**：上不封顶段（max_value=∞）用 NULL 表示，但 SQL `WHERE max_value IS NULL` 与其他段混淆。

**修复**：在应用层按 `seg_order ASC` 线性匹配，min_value 缺失则 `<='` 上封顶。

### 1.3 关联 prcp_rpt_item 字段不存在

**问题**：`rpt_id` 外键 `prcp_rpt_item` 表，服务端用 in line 但 rpt_id 字段在另一张表。

**修复**：调整 KpiController `/rpt-items` 端点，按 rpt_id 查 prcp_rpt_item 而非 prcp_rpt_report。
