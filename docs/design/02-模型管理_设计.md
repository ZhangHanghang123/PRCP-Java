## 二、数据库设计

### 2.1 ER 关系

```
prcp_model (1) ──── (N) prcp_model_version
```

### 2.3 model_type 枚举

| 值 | 中文名 | 默认超参 | 适用场景 |
|---|---|---|---|
| `LINEAR_REGRESSION` | 线性回归 | fit_intercept=true | 简单规模预测 |
| `DNN_NEURAL_NETWORK` | DNN 神经网络 | epochs=500, lr=0.001 | 监管指标综合反算 |
| `ANT_COLONY` | 蚁群算法 | n_ants=50, iterations=200 | 资产负债组合优化 |
| `NONLINEAR_SOLVER` | 非线性方程 | method='lm' | IRRBB/EVE 隐含波动率 |
| `CVXPY_QP` | 二次规划 | solver='ECOS' | 演示型约束求解 |
| `HJM_MODEL` | HJM 利率模型 | factors=3 | 经济情景生成 |
| `SVM_REGRESSION` | 支持向量回归 | kernel='rbf', C=1.0 | 小样本非线性 |

### 3.2 一键训练协议

`POST /model/{mid}/train`
```json
{
  "version_id": null,            // 🆕 可空, 空时取最新版本
  "param_overrides": [           // 可选, 覆盖默认超参
    {"key": "learning_rate", "value": "0.0001"},
    {"key": "epochs", "value": "1000"}
  ],
  "use_existing_param": true     // true: 用 model_param; false: 用 algo_config
}
```

响应:
```json
{
  "code": 0,
  "data": {
    "train_id": 42,
    "model_id": 1,
    "version_id": 5,
    "version_code": "v1.2.0",
    "status": "PENDING",
    "message": "训练任务已入队 (DNN_NEURAL_NETWORK, 500 epochs, lr=0.0001)"
  }
}
```

### 3.3 增量日志协议

`GET /model/{mid}/logs?train_id=42&last_id=0`

响应:
```json
{
  "code": 0,
  "data": {
    "logs": [
      {"id": 1, "ts": "2026-10-10T10:23:11", "level": "INFO", "message": "Epoch 1/500 loss=0.32"},
      {"id": 2, "ts": "2026-10-10T10:23:12", "level": "INFO", "message": "Epoch 2/500 loss=0.28"}
    ],
    "next_id": 2,
    "status": "RUNNING"
  }
}
```

### 3.4 训练状态机

```
PENDING ──train──> RUNNING ──success──> SUCCESS
                      │                    │
                      ├──fail────> FAILED  │
                      │                    │
                      └──cancel──> CANCELLED
```

| 状态 | 颜色 | 动画 |
|---|---|---|
| PENDING | 🟡 黄 | — |
| RUNNING | 🔵 蓝 | 🔄 loading 旋转 |
| SUCCESS | 🟢 绿 | — |
| FAILED | 🔴 红 | — |
| CANCELLED | ⚫ 灰 | — |

## 五、关键设计决策

### 5.1 🆕 单页布局 (无 tab)

**理由**:
- 原 v1 设计 4 tab (`模型管理` / `版本管理` / `参数明细` / `训练记录`), 信息分散
- 新设计主表 + 详情面板, **点击行 → 联动右侧**, 一屏看完
- 一键训练按钮在主操作区, 不必切 tab

### 5.2 prcp_model 加 3 字段 (model_type / biz_domain / kpi_scheme_id)

**理由**:
- **model_type**: 替代旧 `algorithm`, 标准化枚举 (见 § 2.3), 弹窗下拉
- **biz_domain**: 区分 REVERSE (反算) / FORECAST (预测) / OPTIMIZE (优化) 业务域
- **kpi_scheme_id**: 关键! 反算方案选模型时, 自动带出 KPI 评分方案, 引擎按此组装 kpi_schemes 段

### 5.3 算法配置存 JSON 字段 (algo_config)

**vs prcp_model_param**:
- `algo_config` (JSON): 模型级**默认**配置, 不可改
- `prcp_model_param` (key-value): 版本级**覆盖**, 可训练时调

### 5.4 异步训练用 Java 线程池 (而非外部引擎)

**理由**:
- 模型训练 vs 反算求解: **模型训练是 CPU 重活 (Java 线程池), 反算求解是计算活 (外部引擎)**
- 模型训练时长: 5-10 分钟, HTTP 异步 + 增量日志
- 取消机制: `volatile boolean cancelled` 标志位

### 5.5 增量日志 (last_id 游标)

**理由**:
- 训练日志可能几 MB, 不能全量返回
- 前端定时拉 (3s 一次), 追加渲染

## 六、与其他模块的关系

| 模块 | 关联 | 说明 |
|---|---|---|
| **测算方案 (reverse)** | `prcp_reverse_scheme.model_id` | 选模型时拉 `kpi_scheme_id` 自动联动 |

## 七、不在本期范围

- 分布式训练 (单 JVM 线程池)
- GPU 加速 (无 CUDA 集成)
- 模型 A/B 测试 (无分流)
