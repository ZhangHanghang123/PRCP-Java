| 版本 | 日期 | 作者 |
|---|---|---|

## 一、整体架构

```
前端 Vue3 (src/views/reverse/Index.vue)
   ↓
   └── components/DashboardPanels.vue (测算结果驾驶舱)
   ↓
   axios (request baseURL: /prcp-java/api)
   ↓
后端 Spring Boot (prcp-business/com/prcp/business/reverse/)
   ├── ReverseController.java         (方案 / 目标 / 运行 / 算法 / 选项)
   ├── service/ReverseService.java
   ├── result/ReverseResultController.java   (反算结果查询 + 导出)
   ├── result/ReverseResultService.java
   ├── dashboard/ReverseDashboardController.java (驾驶舱 4 端点)
   ├── dashboard/ReverseDashboardService.java
   ├── entity/{ReverseScheme, ReverseTarget, ReverseRun, ReverseRunLog, ReverseResult}.java
   └── mapper/{ReverseSchemeMapper, ReverseTargetMapper, ReverseRunMapper, ReverseResultMapper, ReverseRunLogMapper}.java
   ↓ MyBatis-Plus + JdbcTemplate（动态 SQL）
MySQL 8.0 prcp_db
   ├── prcp_reverse_scheme / prcp_reverse_target / prcp_reverse_run
   ├── prcp_reverse_run_log / prcp_reverse_result
   ├── prcp_data_reverse (结果明细, 57 节点 × 24 月)
   └── prcp_metric_coefficient (KPI 指标数据)
```

## 二、数据库设计

### 2.1 ER 关系

```
prcp_reverse_scheme (1) ──┬── (N) prcp_reverse_target
                          │
                          └── (N) prcp_reverse_run
                                    │
                                    ├── (N) prcp_reverse_run_log
                                    │
                                    └── (N) prcp_reverse_result
                                              │
                                              └── (1) ── prcp_data_reverse
                                                          （明细 24 月 × N 节点）
```

## 五、关键设计决策

### 5.1 4 行布局（按用户偏好）

| 行 | 内容 | 列结构 |
|---|---|---|
| **Hero** | 标题 + 元信息 + 主操作 | 单列 |
| | 筛选条：方案/Run/月份 select | 单列 |
| Row 1 | 8 KPI 卡 (4×2) | 4 列 × 2 行 |
| Row 2 | 趋势图 + 雷达图 | 左 5fr + 右 3fr |
| Row 3 | Top 10 + 大类分布 | 左 1fr + 右 1fr |
| Row 4 | 节点 × 指标 热力图 | 1fr 全宽 |

### 5.2 KPI 阈值准确（**只算叶子节点**）

**关键**：`asset_total = Σ leaf 节点余额`，避免父子节点重复计算。

**判断叶子**：parent_code = N 的子节点集 = `{ M | M.path startsWith N.path + "/" }`  
无节点的 path 中含 N.path + "/" 前缀 → N 是叶子。

### 5.3 雷达图 5 维（ROE/CET1/LCR/NSFR/△EVE）

**分数** = `prcp_kpi_score_segment` 5 段 PIECEWISE 命中段分数。

### 5.4 trend SQL 用 **fallback**

```sql
-- 先按 scheme_code = coaCode 查
SELECT ... AND scheme_code = ?  -- ZXCOA_V1
-- fallback: coa_code 没数据则取全部
SELECT ...  -- 无 scheme_code 条件
```

**理由**：`prcp_metric_coefficient.scheme_code` 实际存的是 `REV_DNN_REG`（反算方案 code），用 coa_code 查不到。

### 5.5 节点 × 指标 **真热力图**（ECharts heatmap）

**替代柱图**：X 轴节点编码 × Y 轴 5 大类，visualMap 色阶 红橙绿蓝。

## 六、与其他模块的关系

- **prcp_data_basic**：基期余额（原 m1）
- **prcp_metric_coefficient**：KPI 数据（ROE/CET1/...，按节点 × 月）
- **prcp_coa_node**：节点名称、节点类型（ASSET/LIABILITY/EQUITY）
- **prcp_kpi_score_segment**：评分段（雷达图分数）
- **指标管理**：KPI 定义（target 反算约束）
