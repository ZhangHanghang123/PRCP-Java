## 一、目标与原则

### 1.1 总目标
将 PRCP（Python + React + AntD）**全量移植**为 **Spring Boot + MyBatis-Plus + Element UI (Vue2)**，覆盖全部 19 个 Python router、208 个 endpoint，达到功能完整、UI 对位、性能不劣化。

### 1.2 工作原则（来自 prcp-java-port skill）
每个模块开发必须按 **四步法**：
1. **分析**：读 Python 端对应 router/service（先看 API 契约，再看算法）
2. **设计**：输出接口对照表 + 文件清单
3. **开发**：单文件 ≤200 行，跨文件 ≥3 走批量链式
4. **对比**：同样数据，比对 Java 端与 Python 端输出

### 1.3 纪律约束（来自 dev-expert）
- 无证据 = 未完成（必须截图 / 单元测试 / 命令退出码）
- 改 mapper XML 必须双份同步（`prcp-business` + `prcp-app`）
- 涉生产配置 / DB 写入先出方案
- 每 Wave 落 `.ai-memory/handoff.md` 检查点

## 五、风险与依赖

### 5.1 技术风险
| 风险 | 影响 | 缓解 |
|---|---|---|
| EasyExcel 内存爆掉（>10万行） | 导出接口 | 加 rowCount 分批，>5k 改 SXSSF 流式 |
| MyBatis-Plus XML 双份同步遗漏 | 启动警告 / 运行时报错 | 提交前用 `git diff --stat` 强制比对 |
| Python Decimal ↔ Java BigDecimal 精度 | 反算数值误差 | 用 `MathContext.DECIMAL64` |
| Python `date` ↔ Java `LocalDate` 时区 | 反算月份偏差 | 统一 UTC + `LocalDate.parse(s)` |
| EasyExcel 对 java.sql.Date 缺 converter | 导出 NPE | 用 `DateUtil.toLocalDate()` 转换 |

### 5.2 业务风险
- **ESG 模块 25 端点**：Python 端代码量大（HJM 模型、PCA 拟合、蒙特卡洛），Java 移植需逐函数对照
- **sim 引擎**：Python 端 5 步算法涉及按月滚动 + 桶推算，必须严格按 64 桶规则

## 六、与 Python 原系统对齐策略

### 6.1 数据层对齐
- 用同一个 MySQL（`prcp_db`），Java 端连接复用
- 字段命名：snake_case（Python）↔ camelCase（Java），靠 MyBatis-Plus `@TableField` 映射
- 主键：Python BigInteger ↔ Java Long（注意 JS Number 上限）

### 6.2 接口契约对齐
- URL 路径：Java 端去掉 Python 的 `prefix`，统一 `/<module>/<action>`
- 响应结构：复用 Python 的 `{code, message, data}` 三段式（已在 GlobalResponseAdvice）
- 错误码：Python `BizException` ↔ Java `BizException`（messageKey 复用）

### 6.3 算法对齐
- Python `Decimal` → Java `BigDecimal`（DECIMAL64 MathContext）
- Python `numpy` 矩阵运算 → Java `ujmp` 或 `ND4J`（仅在 PCA/HJM 处）
- Python pandas → Java 表格类（`TableModel` 内部用 `Map<String, List<Object>>`）

## 七、Skill 工作流应用

### 7.1 每个新模块的开发流程（prcp-java-port 四步法）

```
【分析 Step 1】
1. 读 Python 端 router/<module>.py 所有 endpoint
2. 读 Python 端 services/<module>.py 业务逻辑
3. 用 curl 对照 Python 端的真实响应（截 JSON 存到 docs/<module>-api.md）
4. 列出所有 SQL 表 + 字段

【设计 Step 2】
1. 输出接口对照表（Python URL → Java URL + Param + Resp）
2. 列出 Java 新增/修改文件清单
3. 标注 64 桶 / BigDecimal / Date 等特殊处理点

【开发 Step 3】
1. Controller → Service → Mapper → XML → DTO/VO
2. 改 XML 时**强制双份同步**（prcp-business + prcp-app）
3. EasyExcel 导出统一用 ByteArrayOutputStream 内存拼装
4. 前端用 Element UI 标准组件 + 二级表头（如需）

【对比 Step 4】
1. 用同样的 schemeId/dataDate 调 Java 端 + Python 端
2. diff JSON / Excel / DB 行数
3. 浏览器截图比对（同字段同布局）
4. 写入 docs/<module>-comparison.md
```

### 7.2 dev-expert 兜底
