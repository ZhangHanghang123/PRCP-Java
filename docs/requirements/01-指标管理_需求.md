## 一、业务背景

### 1.1 业务问题

银行经营决策中需要持续跟踪大量监管指标、规模指标、盈利指标、风险指标。这些指标在不同业务场景下口径和计算公式不一致：

- **ROE、CET1、LCR、NSFR、△EVE** 等 5 个核心监管指标 需按月、按方案跟踪达标情况
- 不同指标体系（巴塞尔协议、内部管理、监管报送）需要**多套方案**并存
- 指标值**手工录入不可控**、可重复性差，需要**自动试算** + **评分**
- 需要支持**自定义公式**和**评分规则**（分段打分）

### 1.2 业务目标

建立**统一指标管理平台**：
1. 集中管理所有监管指标 / 业务指标定义（指标口径、计算公式）
2. 支持**多版本方案**（不同口径的并存与切换）
3. 按月**自动试算**指标值
4. 按**评分规则**自动打分
5. 与组合反算驾驶舱联动（KPI 作为反算目标约束）

## 二、用户故事（User Story）

| ID | 角色 | 故事 | 优先级 |
|---|---|---|---|
| US-KPI-01 | 管理员 | 我想**新建/编辑/删除指标方案**（如：中信银行 2026 监管口径、轻量银行试点方案） | P0 |
| US-KPI-02 | 管理员 | 我想为方案**配置指标定义**（指标编号、名称、公式、单位、阈值） | P0 |
| US-KPI-03 | 分析师 | 我想**按月自动试算**所有指标值，无需手工逐个录入 | P0 |
| US-KPI-04 | 分析师 | 我想按**指标评分规则**自动打分（0-100），快速识别风险节点 | P0 |
| US-KPI-05 | 业务人员 | 我想**手动录入**个别指标值（如不能公式计算的） | P1 |
| US-KPI-06 | 业务人员 | 我想查看**指标维护历史**（手动值 vs 试算值的差异） | P1 |

## 三、功能清单

### 3.1 指标方案（Kpi Scheme）

| 功能 | 描述 |
|---|---|
| 列表 | 按方案编码 / 名称筛选；状态过滤 |
| 新增 | 编码、名称、状态、描述 |
| 编辑 | 同上 |
| 设为当前方案 | 单选切换，全局生效 |

### 3.2 指标定义（Kpi Definition）

| 功能 | 描述 |
|---|---|
| 列表 | 按方案筛选，显示公式、单位、阈值 |
| 新增 | 指标编码、名称、公式、单位、阈值（min/max）|
| 编辑 | 同上 |
| 删除 | 软删除（is_deleted=1）|

### 3.3 指标评分（Kpi Score Rule）

| 功能 | 描述 |
|---|---|
| 列表 | 显示某指标的所有规则 |
| 新增 | 区间（min, max）、分数（0-100）、higher_is_better 标识 |
| 编辑 | 同上 |
| 删除 | 软删除 |

### 3.4 指标维护（Kpi Value）

| 功能 | 描述 |
|---|---|
| 列表 | 按方案/日期/指标筛选 |
| 试算 | 按公式 + prcp_data_basic 数据计算，**自动**写入 value 表 |
| 手动录入 | 手工覆盖（calc_source=MANUAL）|

## 四、验收标准

### 4.1 数据完整性

| 指标 | 标准 |
|---|---|
| 方案创建成功率 | ≥99%（含重复编码检查）|
| 指标定义覆盖 | 至少 5 个核心监管指标（ROE/CET1/LCR/NSFR/△EVE）|
| 评分规则覆盖 | 每条核心指标至少 5 段（min_value, max_value, score）|

### 4.2 计算准确性

| 指标 | 标准 |
|---|---|
| ROE 计算 | 与 Python 源系统偏差 < 1e-6 |
| CET1 计算 | 同上 |
| 评分准确性 | 与源系统完全一致 |

### 4.3 性能

| 操作 | 标准 |
|---|---|
| 列表加载 | < 1s（1000 行内）|
| 试算（5 指标 × 12 月）| < 5s |
| 评分计算 | < 1s |

## 五、约束与限制

- 数据库使用 MySQL 8.0，指标公式使用占位符 `${balance_x}`、`${delta_eve}` 等
- 评分规则采用 **5 段 PIECEWISE** 评分（min/max/score）
- 公式计算采用 **JS 表达式引擎**（或自研简易引擎，避免引入 Python 依赖）
- 试算结果**幂等**：同日期同指标，多次试算结果一致

## 六、不在本期范围

- 跨方案合并（不实现方案叠加/对比）
- 公式可视化编排（仅支持纯文本）
- 公式版本管理（同一指标多公式版本）
