## 一、业务背景

### 1.1 业务问题

银行的资产组合优化、IRRBB 反算、利率风险计量 等都需要 **数学模型**（蚁群算法、DNN 神经网络、非线性方程求解 等）。这些模型：

- **多算法并存**：不同业务场景用不同算法（DNN 适合非线性，蚁群适合组合优化）
- **多版本迭代**：同一模型需要多个版本并存（A/B 测试、模型对比）
- **超参数差异**：同一算法不同超参（learning rate、迭代次数）需要分别管理
- **训练过程漫长**：DNN 训练可能数小时，必须**异步**执行 + 实时查看日志
- **训练结果需追溯**：训练指标（loss、accuracy）、训练时长

### 1.2 业务目标

建立**统一模型管理平台**：
1. 管理**算法目录**（DNN、蚁群、NS 求解等 4-5 种）
2. 管理**模型**（属于哪个算法、状态、版本数、最近训练时间）
4. 管理**版本**（模型训练快照、超参）
5. 管理**超参数**（每个版本独立配置）
6. **异步训练** + **实时日志** + **训练结果**

## 三、功能清单

### 3.1 算法目录（Algorithms）

| 算法 | 说明 |
|---|---|
| DNN_NEURAL_NETWORK | 神经网络回归（适合非线性预测）|
| ANT_COLONY | 蚁群算法（适合组合优化）|
| NONLINEAR_SOLVER | 非线性方程求解（适合 IRRBB 反算）|
| LINEAR_REGRESSION | 线性回归（基准对比）|

### 3.2 模型（Model）

| 字段 | 类型 | 必填 | 备注 |
|---|---|---|---|
| model_code | String | 是 | 唯一编码（如 `DNN_REVERSE_REG`）|
| model_name | String | 是 | 显示名称 |
| algorithm | String | 是 | 引用算法目录 |
| description | String | 否 | 备注 |
| status | String | 否 | ACTIVE/INACTIVE |

### 3.3 版本（Versions）

| 字段 | 类型 | 必填 | 备注 |
|---|---|---|---|
| model_id | Long | 是 | 外键关联 model |
| version_code | String | 是 | 如 `v1.0.0` |
| base_version_id | Long | 否 | 复制场景的源版本 |
| train_status | String | 否 | PENDING/RUNNING/SUCCESS/FAILED/CANCELLED |
| description | String | 否 | 备注 |

### 3.4 超参数（Params）

每版一个 params 列表（key/value pair）：

```
[
  {"key": "learning_rate", "value": "0.001", "value_type": "FLOAT"},
  {"key": "iterations", "value": "1000", "value_type": "INT"},
  {"key": "hidden_layers", "value": "128,64", "value_type": "STRING"}
]
```

## 四、验收标准

### 4.1 数据完整性

| 指标 | 标准 |
|---|---|
| 模型注册 | ≥3 个真实模型（DNN/蚁群/NS 求解）|
| 版本管理 | 每个模型 ≥1 版本 |
| 超参数配置 | 每个版本 ≥3 参数 |

### 4.2 训练流程

| 指标 | 标准 |
|---|---|
| 异步启动 | POST /{mid}/train 不等待训练完成 |
| 实时日志 | GET /{mid}/logs 每 10s 返回新日志 |
| 训练结果 | GET /results 返回 loss/accuracy/duration |

## 六、约束与限制

- **Java 进程内线程池**模拟异步（生产环境应替换为 Celery/RQ 等）
- 训练**模拟**用 sleep 线程模型（实际 DNN 训练可对接 PyTorch）
- 训练日志**增量返回**（用 last_id 或 timestamp 增量拉取）

## 七、不在本期范围

- 分布式训练（多机多卡）
- 模型导出（pickle/ONNX）
- 在线推理 API（仅离线训练 + 保存）
- 自动超参搜索（GridSearch/Bayesian）
